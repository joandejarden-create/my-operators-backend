About Client Opportunities / Ready / Action Set / Watch

Client Opportunities is the external client-list count, using the same visibility policy as the client page, counted before presentation sanitization. Ready and Action Set stay the strict current-report metrics. Watch is the future-watch sample in the current report; when the builder caps that sample, the cell says so and is not the full Watch inventory. Last Generated is the PDF store generation time. A PDF or a client link does not by itself mean opportunities are published.
