# Content QA Checklist

Use when reviewing extracted content before platform import or display.

## Source QA

- [ ] Is the source identified?
- [ ] Is the source date known?
- [ ] Is the source region known?
- [ ] Is the source official, third-party, owner-provided, or AI-assisted?
- [ ] Is the source recent enough?

## Extraction QA

- [ ] Are extracted facts separated from interpretation?
- [ ] Are missing fields listed?
- [ ] Are conflicts flagged?
- [ ] Are old sources labeled?
- [ ] Are global sources separated from CALA-specific sources?

## Platform Use QA

- [ ] Is validation status assigned?
- [ ] Is usage permission assigned?
- [ ] Is confidence level assigned?
- [ ] Is external visibility appropriate?
- [ ] Is company-validated data protected?
- [ ] Is the content safe to display?

## Language QA

- [ ] Does the language avoid overclaiming?
- [ ] Does it avoid "validated" unless supported?
- [ ] Does it avoid legal/advisory language?
- [ ] Does it sound like Dealality? See [../ai-build-system/NAMING_AND_COPY_GUIDE.md](../ai-build-system/NAMING_AND_COPY_GUIDE.md)
