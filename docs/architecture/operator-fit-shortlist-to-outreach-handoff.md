# Operator Fit — Shortlist → Outreach Handoff

**Date:** 2026-08-04  
**Status:** Architecture only — **no auto ODR**

---

## Prerequisites before advancing shortlist → outreach

1. Owner/advisor explicitly chooses to advance  
2. No critical eligibility conflict remaining for the chosen lane  
3. Material brand issues identified (relationship vs project approval)  
4. Required **pre-outreach** validations complete (or explicitly deferred with note)  
5. Operator contact identified (or contact-discovery task opened)  
6. Candidate operating structure identified  
7. Outreach objective identified  
8. Current alignment **snapshot preserved** on Shortlist (immutable history)

## What may transfer into Operator Deal Request (when created later)

| Field | Source |
| ----- | ------ |
| Deal | Shortlist / Deal |
| Operator | Shortlist |
| Brand | Shortlist Brand |
| Operating structure | Shortlist |
| Shortlist ID | Shortlist |
| Alignment snapshot | Decision Snapshot JSON |
| Key reasons / concerns / unknowns | Snapshot |
| Validation questions for operator | Rank-change / lifecycle |
| Known brand issues | Brand depth layers |
| Contact | CRM / research |
| Outreach purpose | Advisor note |

## Explicit non-goals

- Do **not** create ODR on shortlist  
- Do **not** collapse Shortlist and Outreach states  
- Do **not** overwrite shortlist snapshots when Fit re-runs
