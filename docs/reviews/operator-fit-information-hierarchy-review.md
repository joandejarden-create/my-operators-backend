**Date:** 2026-08-04  
**Updated with live advisor scorecards**

## First frame — “Which operators appear most aligned and why?”

- Operator name  
- Production vs Under Evaluation (if research ever shown — prefer hide from owners)  
- Project Compatibility state (owner wording)  
- Operator Alignment **band** (numeric demoted)  
- Evidence Strength  
- 1–2 main reasons  
- Thin/zero constrained-universe banner when needed  

**Omit:** claim IDs, factor tables, long unknown lists, Ranking Ready jargon, publication classes.

## Expanded candidate view — strengths, concerns, experience

- Main reasons / concerns  
- Comparables (titles)  
- Brand relationship (not project approval)  
- “Why different?” drivers (≤5)  
- Validate next (material items only)

## Diligence view — evidence & validation

- Evidence Strength detail  
- Important unknowns  
- Project Approval = To Be Confirmed / validation timing  
- Source-backed claims on request  

## Internal-only

- Claim/source graphs · conflict matrices · engine diagnostics · Research Stage production firewall · Wave overlays · advisor scorecards · Market Presence taxonomy internals

## Advisor-driven changes from templates

- Demote numeric score further (Option C)  
- Trim unknowns on first frame  
- Keep comparison + validate-next prominent  
- Never imply project approval from portfolio
