## Controls

| Group | Options |
|-------|---------|
| **Level** | Off · Light · Medium · Bold |
| **Style** | Rise · Cascade · Scale · Slide · Clip |
| **Scroll pull** | Scroll cue · Early reveal · Depth fade · Edge hint |
| **Sections** | Toggle each section’s recommended motion on/off |
| **Replay** | Reset to top and re-run reveals |

URL: `?level=medium&style=rise&cue=1&early=1&depth=0&edge=1&secOff=faq,insights`
