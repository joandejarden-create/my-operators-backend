# Archive

Reserved for clearly outdated documentation that is safe to retire from active use.

**Nothing has been archived yet.**

Before moving a file here:

1. Confirm it is superseded or no longer accurate.
2. Search the repo for links to the file.
3. Add a one-line note at the top of the archived file pointing to the replacement.
4. Update any index or README references.

Do not archive schema docs, runbooks, or audits that may still inform active work without explicit review.
