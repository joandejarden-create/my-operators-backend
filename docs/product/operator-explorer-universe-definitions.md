# Operator Explorer — Universe Definitions

| Concept | Definition |
| ------- | ---------- |
| **Operator Master Universe** | All canonical rows in `Operator Setup - Master` (currently 46). |
| **Real Operator Universe** | Record Purpose = Production **or** Research (excludes Test Fixtures). |
| **Production Operator Universe** | Record Purpose = Production. |
| **Research Operator Universe** | Record Purpose = Research. |
| **Calibration Universe** | The exact 27 entities used in Calibration 01 architecture validation. |
| **Brand-Managed Discovery Universe** | The 34 Brand Basics parents evaluated for management capability (not all are Masters). |
| **Explorer Content-Complete Universe** | Operators whose **content** meets Useful/Strong gates regardless of Record Purpose. |
| **Explorer Publishable Universe** | Production + content-complete (canonical readiness). Research never publishable until graduated. |
| **Fit Data Ready Universe** | Diagnostic: enough structured intel for Fit evaluation discussion. |
| **Fit Production Candidate Universe** | Operators allowed into production Fit candidate selection (report: Production only; Fit engine not rewired here). |
| **Test Fixture Universe** | Synthetic Masters for testing only. |

These sets **overlap** and are **not** expected to have equal counts.
