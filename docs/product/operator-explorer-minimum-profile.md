# Operator Explorer — Minimum Profile

**Date:** 2026-08-09  
**Status:** Draft for founder approval  
**Related:** `docs/data/operator-fit-minimum-viable-operator-profile.md` (Fit-focused) — this doc separates **Explorer Publishable** from **Fit Ranking Ready**

---

## Two gates (not identical)

| Gate | Audience | Bar |
| ---- | -------- | --- |
| **Explorer Publishable** | Owners browsing Operator Explorer | Useful, honest profile with evidence transparency |
| **Fit Ranking Ready** | Operator Fit engine (production lane) | Enough project-relevant structured data to rank without fiction |

An operator may be Explorer Publishable while not Fit Ranking Ready (or the reverse for internal research-stage Fit experiments).

---

## Category requirements

### Identity

| Level | Explorer Publishable | Fit Ranking Ready |
| ----- | -------------------- | ----------------- |
| Required | Legal/trade name; Master Active (or explicit Research Stage internal-only); company type/role clear | Same + Active for production Fit |
| Strongly preferred | Website; HQ country; parent if applicable; **Candidate Type** | Parent; Candidate Type (Third-Party vs Brand-Managed vs Integrated) |
| Optional | Aliases | Aliases |
| Internal only | Internal notes; dummy flags | Record Purpose |

### Scale

| Level | Explorer | Fit |
| ----- | -------- | --- |
| Required | Chain scales supported | Chain scales |
| Strongly preferred | Approximate portfolio size / keys range | Keys range |
| Optional | Employee band | — |
| Internal only | Unverified marketing scale claims | Same |

### Geography

| Level | Explorer | Fit |
| ----- | -------- | --- |
| Required | ≥1 evidenced country with **typed** Market Presence (not strategic interest alone for “operates in”) | Strong presence types for project country **or** honest conditional/unknown |
| Strongly preferred | Multiple countries; city/metro where known | Markets/cities when project-local |
| Optional | Regional office callouts | — |
| Internal only | Strategic interest lists presented as operations | Forbidden as strong geo |

### Portfolio / assignments

| Level | Explorer | Fit |
| ----- | -------- | --- |
| Required | ≥3 verified assignments **or** high-quality case studies with property identity | ≥1 project-relevant comparable / assignment signal |
| Strongly preferred | 5–10 assignments with brand/keys/location | Multiple comps with Comparability Strength |
| Optional | Historical assignments | Historical if labeled |
| Internal only | Unverified scraped lists | — |

### Segment experience

| Level | Explorer | Fit |
| ----- | -------- | --- |
| Required | Chain scales + honest segment narrative tied to evidence | Structured scales matching deal |
| Strongly preferred | Assignment-backed segment tags | Assignment-backed |
| Optional | Lifestyle/AI/extended-stay flags | When deal needs them |
| Internal only | Inferred luxury from one weak example | Never |

### Development experience

| Level | Explorer | Fit |
| ----- | -------- | --- |
| Required | None for thin Explorer if labeled limited | When deal is conversion/new-build — evidenced flag or conditional |
| Strongly preferred | Conversion / new-build / reflag examples | Same |
| Optional | Turnaround, mixed-use, residences | Project-dependent |
| Internal only | Capability claims without properties | — |

### Operating structures

| Level | Explorer | Fit |
| ----- | -------- | --- |
| Required | Management structures supported (structured) | Same |
| Strongly preferred | Third-party vs brand-managed clarity | Same |
| Optional | Hybrid notes | — |
| Internal only | Fees / contract terms | Class 3 |

### Brand relationships

| Level | Explorer | Fit |
| ----- | -------- | --- |
| Required | Brands list (linked) with “experience ≠ approval” honesty | Brands for branded deals |
| Strongly preferred | Current vs historical; evidenced properties | Depth model when available |
| Optional | Soft-brand notes | — |
| Internal only | Project-specific approvals | Outreach only |

### Differentiators

| Level | Explorer | Fit |
| ----- | -------- | --- |
| Required | At least one evidenced differentiator **or** explicit “limited public differentiation” | Avoid generic services-only ranking wins |
| Strongly preferred | CALA depth, conversion, resort, institutional reporting | Project-matched |
| Optional | Recognition / awards | — |
| Internal only | Performance guarantees | Never publish |

### Sources / evidence

| Level | Explorer | Fit |
| ----- | -------- | --- |
| Required | Source basis + last reviewed style footnote; no AI-as-evidence | Evidence class on material Fit inputs |
| Strongly preferred | PI Source Library links | Claims/Presence verification dates |
| Optional | Public source list | — |
| Internal only | Conflict matrices; exception queues | Advisor diagnostics |

---

## Explicit non-requirements for Explorer Publishable

- Full Fit score completeness  
- Fees, capacity, proposed GMs  
- Global brand approvals  
- Performance metrics  
- Exhaustive worldwide assignment inventory
