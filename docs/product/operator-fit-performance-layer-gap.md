# Operator Fit — Performance Evidence Layer Gap

**Project Fit ≠ Performance Evidence.** Current engine scores **fit / eligibility / evidence of capability**, not operating results.

| Metric | Status |
| ------ | ------ |
| RevPAR Index | Future only / mostly unavailable in Fit path |
| RevPAR Index improvement | Future only |
| GOP / EBITDA | Future only |
| Flow-through | Future only |
| Ramp-up / time to stabilization | Future only |
| Forecast accuracy | Future only |
| Direct booking contribution | Future only |
| Labor productivity | Future only |
| Successful turnaround outcomes | Partial narrative via comps/situations — **not** performance math |
| Owner retention / contract renewal | Unavailable in Fit scoring |

**Implemented today:** structured project-fit factors, eligibility, evidence ceilings, risk.  
**Available but unused for performance:** some case-study text may mention outcomes but is not parsed into KPIs.  
**Recommendation:** future **Performance Evidence Layer** complementary to Operator Alignment — never silently mixed into Displayed Alignment without founder approval and separate labeling.
