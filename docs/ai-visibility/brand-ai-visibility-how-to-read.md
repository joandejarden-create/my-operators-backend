# Brand AI Visibility — How to Read

**Help Center guide** · Matches the live Brand AI Visibility page  
**Audience:** Brand development, brand strategy, and commercial leadership  
**Last updated:** 2026-08-17

Use this guide while looking at the page. Section names below match the on-screen headings.

---

## Page map

The page has two tabs at the top:

1. **Executive Summary** — portfolio-level view across your linked brands  
2. **Detailed View** — one brand at a time

Above the tabs you will see:

- Page title and short description  
- **Disclaimer** box (AI outputs can vary; interpret as observed model behavior)  
- **Filters** row  
- **Freshness strip** (Last monitored · Providers completed · Mode)  
- Optional partial-monitoring banner when not all providers finished  

Click **Run Report** after changing filters.

---

## 1. What this page shows

Brand AI Visibility shows how your hotel brands appear when owners, developers, and investors ask AI platforms commercially relevant questions about development, conversion, affiliation, and positioning.

It helps you answer:

- How often does my brand appear?  
- Where is it missing?  
- Do providers differ?  
- Which peers appear instead?  
- Which sources are cited?  
- Does English differ from Spanish (when both are monitored)?  
- Are key public brand / development pages reachable?

It does **not** mean Dealality recommends a brand, that AI “prefers” a brand, or that a cited website caused an answer.

## 2. Filters (top of page)

Every number is scoped by the filters you select, then **Run Report**.

| On-screen control | What it does |
|-------------------|--------------|
| **Geography** | Region for the monitored question set (for example, CALA, Global, North America, Europe) |
| **Provider** | Which AI platform’s answers are measured (OpenAI, Gemini, Perplexity, Claude), or **All Providers** |
| **Language** | Shown when more than one language has completed data (for example, English / Spanish) |
| **Brand** | Detailed View only — which linked brand you are inspecting |
| **Intent** | Detailed View only — optional filter on owner-intent question type |
| **Reset** | Returns filters to the default starting point |
| **Run Report** | Reloads results for the current filters |

**Tip:** Change filters → click **Run Report** → read the freshness strip before interpreting KPIs.

---

## 3. Freshness strip

Before you trust any number, check:

| Label | Meaning |
|-------|---------|
| **Last monitored** | Date of the latest completed monitoring window |
| **Providers completed** | For example, `4 of 4` |
| **Partial monitoring run** | Appears when some providers finished and others did not — unfinished providers are **not** 0% |
| **Mode** | Usually **Latest monitored results** |

This is **not** a live or continuous feed. Results update when a monitoring run is completed (manually governed in the pilot).

## 4. Executive Summary — section by section

Read top to bottom on the **Executive Summary** tab.

### Executive Intelligence (insight tiles)

Up to five evidence-backed takeaways assembled from validated measurement layers:

| Tile type | How to read |
|-----------|-------------|
| **Largest Competitive Gap** | Owner Decision Scenario where your brand is absent while eligible peers appear — only when scenario is **commercially eligible** |
| **Potential AI Perception Gap** | Observed AI claim conflicts with governed Brand Basics on the **same semantic dimension** (e.g., Brand Architecture) — not “AI is wrong” |
| **Observed AI Association** | Validated attribute co-occurring in monitored responses (production-gated; e.g., DISTRIBUTION) |
| **Provider Disagreement** | Material difference between providers on Presence — only when comparability rules pass |

Each tile shows an **evidence line** and **recommended review**. Competitive gap tiles may show an **action disposition** badge:

| Badge | Meaning |
|-------|--------|
| **Action Required** | Eligible scenario gap with persistent evidence — worth owner-facing material review |
| **Review Required** | Gap or signal worth review but not yet action-grade |
| **No Action Indicated** | Expected positioning difference — not an executive problem |
| **Monitor Only** | Early signal — wait for next comparable window |

Use these as the opening narrative. Then confirm each claim in the sections below.

### Portfolio Snapshot

Factual portfolio indicators for your linked brands — **no composite score**.

Typical tiles include:

| Tile | How to read |
|------|-------------|
| **Portfolio AI Presence** | Share of monitored owner questions where **at least one** of your linked brands appeared |
| **Brands Monitored** | How many of your linked brands are included here (for example, `5 of 5`) |
| **Strongest Brand** | Entitled brand with the highest Observed Presence in this geography |
| **Best Competitive Position** | Your brand with the best peer rank in this geography |
| **Questions Missing** | Questions where **none** of your brands appeared in the answer |

### Markets & Movement

| Block | How to read |
|-------|-------------|
| **Regional / Market View** | Table of regions: Brands Monitored, Leading Brand, AI Presence, Best Rank Brand, Competitive Position |
| **AI Presence Over Time** | Line chart across completed monitoring periods (needs enough history; otherwise you will see an empty / insufficient-history state) |

**Not Monitored** in a region means no comparable data yet — not a zero score.

### Visibility Signals

| Block | How to read |
|-------|-------------|
| **Top Strengths** | Highest AI Presence and best peer rank from current monitoring |
| **Gaps / Risks** | Weak coverage, brands not monitored, or questions where brands did not appear |

### Your Brands

Table of all brands linked to this company.

| Column | How to read |
|--------|-------------|
| **Brand** | One row per linked brand. Click a row to open **Detailed View** for that brand. |
| **AI Presence** | How often this brand appeared in monitored AI answers. Higher % = more appearances. `0%` = monitored but not observed. `—` / Not Monitored = no data yet. |
| **Δ vs prior run** | Change in AI Presence vs the previous comparable run, in percentage points (pp). May show Not Comparable or Insufficient History. |
| **Competitive Position** | Rank by AI Presence among the fixed peer set (for example, `#1 of 15`). Based on Observed Presence only. |
| **Questions Missing** | Shown as `% (count)`. Open Detailed View → **Questions Missing Watchlist** for the exact questions. |
| **Top Decision Territory** | Owner-intent question family where this brand appeared most often — not a weighted priority score. |

### Peer Context & Next Review

| Block | How to read |
|-------|-------------|
| **Competitive Snapshot** | How your portfolio compares with peers under the current filters |
| **Priority Review** | Evidence-backed items worth reviewing next |

### Evidence, Sources & Discovery

| Block | How to read |
|-------|-------------|
| **Citation Intelligence** | Whether monitored answers included citations, and owned vs third-party patterns |
| **Source Landscape** | Domains cited most often (citation frequency). Frequency ≠ influence or ranking power. |
| **Provider Visibility** | How Presence looks across providers for the portfolio / cohort |
| **Public Discoverability** | Separate public-URL baseline — not an AI Presence score |
| **Language Comparison** | English vs Spanish (or other languages) when both are monitored for a comparable cohort |

## 5. Detailed View — section by section

Open **Detailed View** from the tab, or by clicking a brand row in **Your Brands**.

### Brand Overview

Insight tiles for the selected brand and current filters.

### Brand Detail

Topline KPIs for the selected brand (Presence, Competitive Position, Questions Missing, and change when available), plus the detail freshness strip.

### Trends

Change across completed comparable monitoring runs for this brand. Insufficient history is shown explicitly — not as zero change.

### Coverage Diagnostics

| Block | How to read |
|-------|-------------|
| **Provider Presence** | Per-provider Observed Presence. **Not Monitored** and provider errors never display as `0%`. |
| **Owner-Intent Coverage** | Presence by owner-decision question family (prompt family) — for example, Conversion, Branded Residences, Soft-Brand Affiliation |

### Questions Missing Watchlist

Monitored questions where this brand was **not observed**.

Watchlist modes:

| Mode | How to read |
|------|-------------|
| **Questions Missing** | Questions where the subject brand was absent |
| **Peers Appearing Where We Are Not** | Cases where peers appear and your brand does not |

Table columns typically include: Question · Prompt Family · Provider · Region · Language · Status · Peers Present · Evidence.

Use **Prompt family** to focus on one intent territory. Open **Evidence** to read the actual monitored answer.

### Competitive / Peer Analysis

How this brand ranks among the fixed peer set in the selected geography and provider.

**Note:** Peer rank requires a **specific provider**. Under **All Providers**, use provider-specific views for rank.

### AI vs Dealality Context (Truth Layer)

When available: observed AI answer pattern next to governed Brand Basics facts on the **same dimension**.

- **Potential AI Perception Gap** — explicit conflict (e.g., AI lists brand among “soft brands” while Brand Architecture = Hard Brand)
- **Aligned** — compatible terminology
- Sections hide when empty — not a failure state

Census-backed footprint truth is **deferred** in V1; this layer uses Brand Setup / Brand Basics only.

### Review Items

Monitoring findings with linked evidence for this brand.

### Citation & Source Intelligence

| Concept | How to read |
|---------|-------------|
| **Citation Rate** | Share of responses with at least one citation |
| **Owned Source Coverage** | Share of responses citing at least one configured brand / parent / development domain |
| **Cited Sources** | Domains associated with answers — not proven causes of Presence or Missing |

### Public Discoverability

Public accessibility of official brand sources — factual baseline only, **not a score** and **not AI Presence**.

Example states you may see:

- **BASELINE_MEASURED** — a governed public check has been completed  
- **CHECK_NOT_RUN** — the check has not been run yet  

### Language Comparison

When both languages are monitored for a comparable cohort, compare Presence / Missing side by side. Differences are observed — not proof of market preference.

### Opportunity Engine

Reserved / future workflow area. Do not treat an empty Opportunity Engine as a Presence failure.

## 6. Provider vs All Providers

| Selection | How to read |
|-----------|-------------|
| **OpenAI / Gemini / Perplexity / Claude** | Results from that provider’s completed monitoring only. Use this for Competitive Position rank. |
| **All Providers** | A **derived** comparison across completed providers — averages / missing-across-all / disagreement. **Not** a fifth combined AI model. |

**Practical tip:** Start with one provider for a clean story. Switch to **All Providers** when you want to show disagreement or “missing on every provider.”

---

## 7. Evidence drawer

When you open **Evidence** from a Presence or Missing row, you should see:

- The monitored question  
- The provider response for that run  
- Associated citations when available  

Use evidence to verify what the model said before deciding what to do internally. One response is not permanent truth — outputs can vary by run and provider.

## 8. Suggested first-read path (matches the page)

1. Confirm **Geography**, **Provider**, and **Language** → **Run Report**.  
2. Read the **freshness strip**.  
3. Scan **Executive Summary** insight tiles.  
4. Read **Portfolio Snapshot**.  
5. Scan **Your Brands** (strongest vs weakest).  
6. Click your hero brand → **Detailed View**.  
7. Check **Coverage Diagnostics** (Provider Presence + Owner-Intent Coverage).  
8. Open **Questions Missing Watchlist** → one Evidence row.  
9. Skim **Citation & Source Intelligence**.  
10. Check **Public Discoverability** as a separate diagnostic.  
11. If needed, switch **Language** or **All Providers** and compare.

## 9. Common misreads

| Misread | Better reading |
|---------|----------------|
| “High Presence means AI recommends us.” | Presence means the brand was **observed** in monitored answers. |
| “Missing means our brand is weak.” | Missing means absent from that answer under these filters. |
| “All Providers is the true score.” | It is a **derived comparison**, not a combined model. |
| “A competitor domain was cited, so it caused our miss.” | Citations are **associated**, not causal. |
| “Discoverability is low, so Presence is low.” | They are **separate** diagnostics. |
| “Not Monitored means 0%.” | Not Monitored means **no comparable data yet**. |
| “This is live.” | You are viewing the **latest completed monitoring window**. |

## 10. Short glossary (on-page terms)

| Term | Meaning |
|------|---------|
| **AI Presence** | Share of monitored questions where the brand was observed in the answer |
| **Portfolio AI Presence** | Share of questions where at least one linked brand appeared |
| **Competitive Position** | Rank by AI Presence within the fixed peer set |
| **Questions Missing** | Monitored questions where the brand was absent |
| **Δ vs prior run** | Presence change vs the previous comparable monitoring run (pp) |
| **Top Decision Territory** | Prompt family with the strongest Presence for that brand |
| **Owner-Intent Coverage** | Presence by question family |
| **All Providers** | Derived multi-provider view — not a combined AI run |
| **Public Discoverability** | Public URL / content baseline — separate from Presence |
| **Evidence** | The monitored question + response (+ citations) behind a fact |
| **Owner Decision Scenario** | Governed owner-intent question family (Conversion, Collection / Soft Brand, Branded Residences, etc.) |
| **Competitive Gap** | Peer-present / brand-missing pattern in an eligible scenario |
| **Potential AI Perception Gap** | AI claim vs governed fact on the same semantic dimension |
| **Observed AI Association** | Validated attribute pattern in responses (not causal) |
| **Action Required / Review Required / No Action Indicated** | Commercial interpretation of whether a gap is an executive problem |

---

## 11. Sharing tip

When you circulate a finding internally, always include:

1. Filters (Geography · Provider · Language · Brand)  
2. Last monitored date  
3. The on-screen section where you found it  
4. One Evidence example  

Separate **observation** from **recommended action**.
