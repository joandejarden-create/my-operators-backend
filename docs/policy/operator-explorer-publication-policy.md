# Operator Explorer — Publication Policy (Draft)

**Date:** 2026-08-09  
**Status:** Draft — aligns with `lib/operator-intelligence/publication-policy.js` and governance docs  
**Do not** treat this as applied Airtable automation.

---

## Auto-publish objective verified facts

Examples:

- Official identity / trade name  
- Headquarters / official website  
- Current hotel assignments (named, located)  
- Current portfolio facts with primary sources  
- Documented offices / regional teams  
- Brands **operated** (experience) with evidence  
- Keys / rooms when from authoritative sources  

Requirements: primary authoritative source **or** two consistent independent sources; no hard conflict; not stale.

---

## Auto-publish with evidence qualification

Examples:

- Development expertise (conversion, new-build)  
- Segment experience summaries  
- Resort / urban / mixed-use experience  
- Strategic capabilities that are more than table stakes  

Label as evidence-qualified / operator-reported when marketing-only.

---

## Internal / validation required

Examples:

- Performance claims  
- Owner satisfaction  
- Current available capacity  
- Proposed personnel  
- Fees / contract terms  
- Project-specific brand approval  
- Interest in a specific project  
- Competitive conflicts / litigation  

Class 3 — outreach / diligence, not Explorer hero content.

---

## Never infer automatically

Examples:

- Global brand approval from one assignment  
- Current presence from strategic interest  
- Luxury expertise from one weak example  
- Performance quality from portfolio size  
- Local resources from company scale alone  
- Current relationship from historical assignment  
- AI summaries / search snippets as evidence
