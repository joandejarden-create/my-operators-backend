# 07 — Performance UI

Hierarchy on Performance tab:

1. **Business outcomes** — Tier 1 (pilots, opps, proposals, customers, revenue, retention) — same board as Brief; gaps stay UNKNOWN/DATA_GAP
2. **Accountability rows** — Did / Expected / Happened / Learned / Change
3. **Channel diagnostics (Tier 3)** — measurement_state only; labeled diagnostic, not commercial success

Vanity metrics (likes, impressions, sessions) never lead the page.
