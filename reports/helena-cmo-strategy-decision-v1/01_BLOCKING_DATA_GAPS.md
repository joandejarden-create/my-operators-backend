# Blocking vs non-blocking data gaps

## Minimum evidence threshold for a strategy recommendation
Locked founder GTM/ICP/positioning + product maturity for entry offer + public identity check (live site) + honest measurement status + LinkedIn role evidence + commercial access hypothesis (warm network OR explicit cold motion). Named CRM rows and live GA4 are NOT required to recommend a near-term GTM strategy.

## Gap classifications
| Gap | Class | Why |
|-----|-------|-----|
| Live GA4 API | **IMPORTANT_BUT_NON_BLOCKING** | Changes channel diagnostics and CTA measurement; unlikely to change ICP/GTM category choice. |
| Live GSC API | **OPERATIONAL_LATER** | SEO priority already MIXED_WEAK from stale snapshot; live refresh refines defense, not strategy. |
| LinkedIn analytics API | **IMPORTANT_BUT_NON_BLOCKING** | Role can be set from content history + engagement quality proxy; ROI remains UNKNOWN. |
| Webflow CMS API inventory | **IMPORTANT_BUT_NON_BLOCKING** | Public HTML inventory resolves what prospects see TODAY; CMS helps editorial ops later. |
| Named commercial pipeline (warm ADP accounts) | **BLOCKING_FOR_STRATEGY** | If warm ADP-relevant owners do not exist, near-term paid-pilot thesis weakens and sequencing must shift. _Blocking for confident ADP-entry EXECUTION sequencing and for strategy LOCK confidence on access — not blocking for discussing the recommended strategic choice. Founder relationship input closes this._ |
| Email/outreach attribution | **OPERATIONAL_LATER** | Required for learning loops; does not choose category/positioning. |
| Conversion-grade public proof | **IMPORTANT_BUT_NON_BLOCKING** | Affects conversion rate and messaging strength; strategy still leads with paid learning to CREATE proof. |

## Data completeness decision
**PARTIALLY** — Remaining gaps (live GA4/GSC, LinkedIn API, outreach attribution) are unlikely to flip category/positioning. Named warm-owner access confirmation COULD change confidence in ADP-entry sequencing or force a temporary dealmaking-only commercial focus — so gaps are partially material to execution sequencing, not to the recommended strategic territory.
