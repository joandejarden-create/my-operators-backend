## Confirmations

- Generic service breadth does not create positive differentiation.  
- Unsupported completeness does not create Strong confidence.  
- Directly relevant evidence can outweigh portfolio breadth.  
- Unknown fields do not increase the score (denominator rule retained).  
- Adding descriptive marketing content is not used as evidence.  
- Adding verified comparable assignments improves alignment/evidence.  
- Adding verified geography changes eligibility (Arbor Mexico office/development; Aimbridge Mexico; GHL LatAm).  
- Adding supported structures changes eligibility.  
- Removing generic detail does not materially reduce ranking (Fit v2 table-stakes rules).  
- Overstated Airtable geography for Cenote was **replaced**, not rewarded.
