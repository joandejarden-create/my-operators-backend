# Funnel Definitions (V5)

| Stage | Definition |
|-------|------------|
| SIGNAL | Interesting market activity only (expansion, conference exists, project announced). Not research-worthy alone. |
| RESEARCH_LEAD | Valid entity + market relevance + plausible future group motion + ≥2 concrete supporting signals. Justifies targeted page research. |
| CANDIDATE_OPPORTUNITY | Organization + group motion + future decision/cycle + plausible lodging need + hotel fit + buyer/organizer path (or clear resolve path). Page-validated. |
| CUSTOMER_READY_OPPORTUNITY | Passes canonical isGdiCustomerOpportunityReady() — no manual promotion. |

**Hard rule:** SIGNAL cannot promote directly to CANDIDATE. Page validation required before CANDIDATE.
