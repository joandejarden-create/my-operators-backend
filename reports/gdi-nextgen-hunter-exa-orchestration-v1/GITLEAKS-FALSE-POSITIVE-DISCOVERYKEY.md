# Gitleaks false positive — discoveryKey (PR #225)

## Finding
- Rule: `generic-api-key`
- Files: `reports/gdi-nextgen-hunter-exa-orchestration-v1/**/**-orchestration.json`
- Line pattern: `"discoveryKey": "disc_<hex>"` (e.g. `disc_cc8d1140e1905f58`)

## Why not a credential
- Values are local orchestration correlation IDs generated by Hunter→Exa adapters.
- Prefix `disc_` + short hex; entropy flagged only because the JSON key ends in `Key`.
- No provider tokens, no `.env` secrets, no paid-API credentials in these reports.
- CI artifact for failing run: GitHub Actions gitleaks on commit `874c2c9` (3 identical findings).

## Correction
- Narrow `.gitleaks.toml` regex allowlist for `"discoveryKey":` (same class as `dedupeKey`).
- Secret scanning remains enabled; no global disable.
