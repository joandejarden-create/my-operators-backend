# ADP Proof / Instrumentation — Minimum System

Required before/during any pilot (JD-6B-001: proof over low-evidence content).

## Baseline
- Hotel identity / market
- Monitored models
- Prompt / demand territory set
- Initial visibility
- Initial competitive visibility
- Source evidence
- Narrative gaps

## Action
- Recommendations made
- Recommendations accepted
- Actions implemented + dates

## Movement (monthly)
- Visibility change
- Demand-territory change
- Competitor change
- Narrative/source change

## Customer
- Usefulness feedback
- Valuable actions
- Continuation intent
- Expansion intent
- Objections

## Commercial
- Pilot price class (MARKET_TEST_DEFAULT / CUSTOM / ENTERPRISE_TBD)
- Start / completion
- Renewal / continuation
- Hotel expansion
- Revenue

**Forbidden:** booking/revenue causality unless directly measured. Investment hurdle ≠ ROI proof.
